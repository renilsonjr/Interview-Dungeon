Progress should
mean something.

A game can make practice feel better. It should also make your next step clearer.

Readiness

See where you stand for a specific path. Requirements are marked Official, Reported, or Estimated so a guess is never presented as a fact.

Experience

XP recognizes your effort and only goes up. It stays separate from readiness, which reflects what you’ve proven for a path.

Shared skills

The full game is designed around one shared skill tree. Practice on a skill can help every dungeon that asks for it.

A few things
before you enter.

Is Interview Dungeon a full game yet?+

Not yet. The project is in the design stage. You can play a shortened Floor III demo from the Google SWE Intern path today.

Do I need to install anything?+

No. The prototype runs in your browser, including its Python coding exercises.

Where is my progress saved?+

Demo progress is stored in your browser only. Nothing is sent to a server.

Is the project affiliated with Google?+

No. Company names describe the interview target a path prepares for. Interview Dungeon is not affiliated with those companies.
