# Intellectual property and content rules

These rules apply to code, content, art and documentation in this repository.

## Problems and challenges

- Every problem is **original**. Problems are generated or written to practice a
  pattern (prefix sums, BFS on a grid...), with their own story and wording.
- **Never copy** problem statements, examples or test cases from LeetCode,
  HackerRank, Codility or any other platform. Patterns aren't owned by anyone, but
  their text and tests are.
- Every problem goes through review before it reaches the game: a reference solution
  and a separate brute-force solution must agree on all tests, and a person approves it.

## Diablo

- Diablo 1 is **visual inspiration only**: dark gothic screens, a character sheet,
  orbs, a descent through floors.
- Don't use Blizzard's names (including "Diablo" in the product), logos, art, fonts,
  music, or character and boss names.
- Generic fantasy words such as Warrior, Rogue, Sorcerer, Barbarian or dungeon are fine.
- Fonts must be free to use (for example, Google Fonts).

## Company names

- Company names (Google, Ramp, Mercury...) are only used to describe the role a path
  prepares for.
- Don't use company logos or anything suggesting endorsement.
- Every path shows: *"Not affiliated with [company]."*

## Interview information

- Describe **formats, lengths and topics**. Don't post questions candidates agreed to
  keep confidential.
- Every requirement carries a trust label: Official, Reported or Estimated.
